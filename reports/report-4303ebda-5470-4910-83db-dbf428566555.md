### W-003 — reproduction

Demonstrates that the /rest/user/whoami endpoint returns 200 without authentication, confirming broken access control.

```python
import sys
import requests

base = sys.argv[1].rstrip('/')
url = f"{base}/rest/user/whoami"
try:
    r = requests.get(url, timeout=5)
    print(f"Status: {r.status_code}")
    if r.status_code == 200:
        print("WEAKNESS REPRODUCED: Endpoint accessible without authentication.")
    else:
        print("Not reproduced or unexpected status.")
except Exception as e:
    print(f"Error: {e}")
    print("Not reproduced.")
```

**Fix.** Require authentication for the endpoint and enforce authorization checks before returning user data.
